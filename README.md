# BRAC SkillConnect

## 📌 Project Overview

A web-based Student Skill & Club Event Management System built using Django and MySQL concepts.

## 🚀 Features

* Student registration and profile
* Skill management with proficiency
* Search & filter students
* Skill distribution report
* Club & event management
* Participation tracking
* Most active student report
* Most popular club report

## 🛠 Tech Stack

* Backend: Django (Python)
* Database: SQLite (designed for MySQL)
* Frontend: HTML, CSS

## 📊 Database Concepts Used

* Normalization
* One-to-Many & Many-to-Many relationships
* Aggregation (COUNT)
* Filtering queries

## ▶️ How to Run

```bash
pip install -r requirements.txt
python manage.py runserver
```
